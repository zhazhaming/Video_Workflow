## 4. 时间轴与卡点规则

1. 镜长 = max(规划, 台词排布需求)，0.5s 倍数；硬切点 `0/6.0/16.0/25.0/41.0/56.0/65.0/75.0/89.0(→实测)`。
2. 蜡烛行军：普通岁 6-51 帧/根（按章预算分配，最大余数法）；事件岁进入慢放窗口（T1=105f / T2=75f / 收官=120f），事件起始帧吸附 0.5s 网格（15 帧倍数），修正量摊到前 ≤5 根普通蜡烛。
3. 章内 LEAD=15f 图表入场预留；每章蜡烛数与预算见 §2。
4. **卡点表（规划值，设计脚本输出为定稿）**：事件 impact（T1 0.72 / 跌+0.06 / T2 0.55 / 收官 1.0 全曲最强）+ 9 镜切 impact（hook 0.80/statement 0.50/march 0.55）+ 30/35/60/78 前 1.5s riser + 行军段每 5 岁 tick 0.12 + 尾部 1.1s 淡出。
5. BGM：`gold_race_bgm.mp3` 基底 ×0.55 + impact/riser/tick 烘焙 → `life_kline_bgm.mp3`（与卡点表同一批秒数）。

## 5. ★ 运镜与特效规范（用户核心要求：不生硬、多特效、多种运镜）

### 5.1 相机层（LifeKline 图表容器整体 transform）

| 场景 | 运镜 | 参数 |
|---|---|---|
| S1 hook | 大远景拉回揭示 | scale 1.28→1.0 + translateY 26→0，ease-out 22f；K 线全貌逐根闪绘 |
| 行军常态 | **缓慢推进 + 呼吸漂移** | scale 1.00→1.08 沿章线性推进；x=sin(t·0.31)·7px、y=cos(t·0.23)·5px 永不静止 |
| 事件慢放 | **punch-in 推近** | 焦点向事件蜡烛偏移（transform-origin 移到 headX/headY），scale→1.12，snappy 8f，出窗 10f 回落 |
| 暴跌事件 | 下坠感 | 事件头 12 帧 translateY +14px→0 衰减 + 常规抖动（≤10px）+ rotate 0.3° 微倾 |
| 涨停/封板 | 上扬 | 事件头 12 帧 translateY −10px→0 + 金色辉光脉冲 |
| S8 收官 | **推近定格** | 最后 4 根蜡烛段 scale→1.15，慢 dolly 到最后一根；定格时全图其余区域亮度 ×0.55（聚光） |
| S9 statement | 拉远收束 | 图表缩为徽标：scale 1.15→0.92 + 上移，16f |

约束：所有运镜走 `look.motion.easing`（snappy）；漂移必须为亚像素级连续函数（禁线性突变）；事件窗口内运镜目标点固定于事件蜡烛，避免视角乱跳。

### 5.2 特效层（叠加于图表之上，均低透明度、纸感兼容）

| 特效 | 触发 | 实现 |
|---|---|---|
| 头蜡烛辉光 | 常驻 | headX/headY 径向渐变光斑，0.5s 节拍脉冲（`frame%15`），事件时增强 |
| 全屏闪光 | 事件头 6 帧 | 红/绿随 kind（age18 用 ink 灰闪、age78 绿闪），opacity ≤0.26 衰减 |
| 冲击环 ×2 | 事件头 | 自事件蜡烛扩散 2 道圆环（stroke 4px→0，0.9s） |
| 事件卡 | 事件窗口 | 纸卡 spring 弹入（scale 0.92→1 + translateY 14→0），虚线连接蜡烛→卡片，出窗 10f 淡出 |
| 负债区 | y<0 | 红色斜纹背景（repeating-linear-gradient 4% 透明度）+「融资余额」挂签随曲线左移；30 岁破零瞬间 0 轴红闪 |
| 天花板线 | 100 万 | 虚线常驻（support 色 30%）；age60 起点亮为金色（accent #B98A2F）+「普通人涨停板」标签 |
| 金色粒子 | age60 封板 | 18 颗金尘自蜡烛升起（1.2s，随机相位） |
| 灰烬粒子 | 退休章 | 8 颗灰点缓落（6s 循环，opacity 0.18） |
| 流光扫过 | 每章切入 | 对角高光带 0.6s 扫过图表区（白 6% 线性渐变） |
| 速度线 | 快速行军段（<8f/根） | 头部后方 4-6 条水平细线拖尾（ink 8%，长度随速度） |
| 章节调色 | 按章 filter | 发行期 sepia(0.35) → 成长 none → 危机章 saturate(1.15) → 封板 golden 辉光 → 退休 grayscale(0.45) → 清盘 grayscale(0.7) contrast(1.1)；filter 变化用 12f 过渡 |
| 下一支重生 | S8 尾 | age78 定格后：右侧虚线幽灵蜡烛 2 根从 0 长出（1.2s，30% 透明度）+「下一支 · 天使轮 ¥400,000」小签 |
| 图例/口径 | 常驻 | 右下「红涨 · 绿跌」+「设计测算口径」小字（support 色 11px 级） |

### 5.3 常驻元素

顶部：kicker（章名）+ `AGE 34` odometer（翻牌）+ 净资产 odometer（万元，负数红色）+ 年份涨跌 pill；轴底：人生阶段色带（发行/成长/加杠杆/慢牛/冲刺/退休，当前章高亮）+ 每 5 岁 tick 刻度；底部：字幕带（bottom:150，与 mix_motion_track 同落点公式）。
