## 2. 逐日行军核心机制（march 版式）

1. **固定坐标系**：x = 全年 242 个交易日槽位，y = [3540, 4300]；三章共用同一坐标系（硬切后曲线从上一镜终点继续），4000 点关口加粗虚线 + 3600/3800/4200 细虚线，月份刻度在轴底。
2. **天数→帧分配**（Python 设计脚本计算，±0 帧对齐）：
   - 普通交易日 = 2~3 帧（快速行军，日期/价格/涨跌 pill 逐日翻转，曲线生长一格）；
   - 事件交易日进入**慢放窗口**（T1=108 帧 / T2=78 帧 / 收官 today=126 帧）：曲线定住，价格冻结，事件卡弹入；
   - 事件日**起始秒吸附 0.5s 网格**（15 帧倍数）：修正量摊到前 5 个交易日（每日 ≤3 帧），肉眼无感。
3. **事件特效（暴涨/暴跌重点关注）**：impact 重音（烘焙在 BGM）+ 前 6 帧全屏闪光（涨=红 `#C8452D`，跌=绿 `#1E7A55`，A股红涨绿跌）+ 屏幕位移抖动（跌=下坠感，涨=上扬，衰减 ≤10px）+ T1 事件径向冲击环 ×2 + 事件卡（标题 + 涨跌幅 + 一句成因）从曲线点弹出。
4. **常驻元素**：顶部 kicker + 交易日计数（DAY 128/242）；巨大价格 odometer + 当日涨跌 pill + 日期；轴下 242 根沪市成交额迷你条形（事件日高亮）；底部字幕带逐句同步（与 mix_motion_track 落点公式一致）；右下角常驻"红涨 · 绿跌"图例。

## 4. 时间轴与卡点规则（实测定稿 2026-11-03）

1. 镜长（durationSec，0.5s 倍数）：`5.5 / 14.5 / 16.5 / 23.0 / 10.5 / 5.5`，硬切点 = `0 / 5.5 / 20.0 / 36.5 / 59.5 / 70.0s`，**总长 75.50s（2265 帧）**；设计脚本按配音实测时长自动上调镜长并保持 0.5s 网格。
2. 事件慢放窗口（15 帧倍数）：T1=105 帧（3.5s）/ T2=75 帧（2.5s）/ today=120 帧（4.0s，全片最长）。
3. **事件卡点定稿表**（全局秒，BGM impact 已烘焙同一批秒数）：
   `nov21@7.0 · jan05@12.0 · febtop@17.5 · mar23@22.0 · apr08@27.0 · may13@32.5 · jun22@38.0 · jul17@43.0 · oct30@52.0 · today@55.5`
   重音强度：today 0.85（全曲最强）> mar23/jul17/oct30 0.78（暴跌加成）> apr08/jun22 0.72 > T2 0.55；镜切 0.5-0.8；mar23/jul17/today 前 1.5s riser；行军段每月首个交易日轻 tick ×10；尾部 1.1s 淡出。
4. **台词起点对齐事件窗口**（align_march_lines）：第 i 句解说领先第 i 个事件窗口 ≤1.2s，通过给前句垫 duration_sec 实现（音频排布/字幕带同公式 → 音字画同步）；硬约束 Σ句帧+镜尾 ≤ durationSec×30，切点零漂移。
   实测起点：marchA `0.50/5.59/10.59`、marchB `0.80/5.94/11.30`、marchC `0.30/5.30/14.33/18.03`。
5. 配音：edge-tts 云健 +10%，逐句实测（14 句，s01_0=1.84s … s06_0=1.95s）。

## 5. 验收标准

- [ ] 全片 1080×1920@30，总长 75.5s±0.5s
- [ ] 曲线 242 个交易日全部逐日出现（普通日 2-3 帧跳跃），日期/价格/涨跌 pill 同步翻转
- [ ] 10 个事件慢放窗口起始帧与 BGM impact 逐点对应（±1 帧）；T1 有冲击环+闪光+抖动，today 为全片最强卡点
- [ ] 三章共用坐标系，切镜处曲线无缝续接；4000 点关口线贯穿
- [ ] 5s 钩子：t0 大数字盖章 + 迷你曲线闪绘 + 承诺语，前 5s 内 ≥2 次音乐重音
- [ ] 字幕带逐句与配音同步（与 mix_motion_track 同一落点公式）
- [ ] 无行星/星空元素；红涨绿跌图例与数据口径落款常驻；2026-11-02 为数据截止日
