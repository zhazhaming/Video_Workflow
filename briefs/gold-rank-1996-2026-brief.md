# 《国际金价排行榜 1996—2026》Remotion 视频制作简报（从零提示词包）

> 用途：把本文件整段交给 agent，由 AI 从零编写全部画面与动效代码。
> 模板相关性判定：**无关 → from_scratch**（见 `gold-rank-1996-2026-plan.json`）。
> 本简报不依赖任何现有模板（不使用 DataVideo.tsx / dv/* 场景与词表），仅复用 Remotion 宿主工程与无版权 sfx 资产。
>
> **⬇ v2 修订（2026-11-01，按用户反馈）：竖屏 + 配音 + 真曲 BGM + 暖调去 AI 味背景，见文末第 8 节。**

## 2. 素材

- BGM：`public/bgm/gold_race_bgm.mp3` —— 本片**专用程序化生成曲**（无版权，BPM=120，拍=0.5s，小节=2s）。
  **卡点表（秒，音乐内已埋 impact 重音，画面事件必须吸附其上）**：
  6.0 竞速开始 · 26.0(2006 爆增) · 30.0(2008 爆跌) · 36.0(2011 冲顶) · 40.0(2013 崩盘) ·
  44.0(2015 筑底·低点) · 54.0(2020 疫情) · 62.0(2024) · **64.0(2025 史诗暴涨·全曲最强)** · 66.0(2026) · 68.0(片尾颁奖) · 74.0 收束
  节拍网格：每 0.5s 一拍、每 2s 一小节；所有年份切换、数字跳动、榜单重排必须落在小节线（±0 帧）。
- SFX：`public/sfx/impact.wav`、`riser.wav`、`whoosh.wav`（片头/片尾/大事件点缀，音量 0.4~0.6，勿盖 BGM）。
- 画面全部代码绘制（终端行情风 + 金色尘埃 + SVG 图表），**零图片素材**。

## 3. 全局风格（统一视觉语言）

- 底色：深炭黑蓝 `#0b0d12 → #12151d`；主强调：金 `#f5d061→#b8860b` 渐变、点睛 `#ffd166`；
  涨 `#00e096` / 跌 `#ff4d5e`；文字奶油白 `#f5efdc`。
- 字体：标题微软雅黑 900；数字/价格 Cascadia Code / Consolas 等宽。
- 质感：全局细颗粒（opacity≈0.04，确定性伪随机）+ 暗角；背景为暗色行情终端：淡烛式网格线 + 缓慢漂移的金色尘埃（暖色圆点，**严禁星点/星空**）+ 顶部金色柔光。
- 卡点脉动：全片按 0.5s 拍网格做指数衰减缩放脉动（幅度 0.5%~1.2%），大事件帧做全屏闪光（涨=金、跌=红）+ 屏幕位移抖动（衰减 ≤6px）。
- 渲染性能：全部 transform/opacity；`spring()` 入场、`interpolate()` 线性段；确定性随机（渲染安全）。

## 4. 逐段脚本

### 片头（0–6s，bar0–2）
0–2s 黑场起，金色尘埃上浮 + 老虎机式滚动数字预热；f15 主标题「黄金三十年」stamp 落地（金色光晕）；f30 副题「国际金价排行榜 · 1996—2026」；
2–4s 三枚数据 pill 弹入（31 年 / 年均价口径 / 累计 ≈11 倍）；底部年份磁带滚动条；
4–6s riser + 画面轻微放大，6.0s 整 impact + 金色闪光 → 硬切竞速。

### 竞速（6–68s，bar3–32，每年=1 小节=60 帧）
**布局**：左侧 55% 为 TOP8 排行榜（名次圆牌：前三金银铜；年份徽标 + 金色价格条 + 等宽价格数字 + 同比%胶囊）；
右侧 45% 为 30 年趋势图（金色渐变面积线，逐年生长，发光播放头按拍脉动，事件旗标弹出）；
顶部：标题 + LIVE 徽章；中部巨幅价格计数器（**里程表式逐位滚动 + 年切换 spring 弹跳 + 同比红绿闪烁**）；右上巨年份数字按拍 pop。
**每年节拍动作**（落在小节线）：新年份金条从右侧 spring 滑入（NEW 徽章闪烁）、旧排名 spring 重排、被挤出者下滑淡出；巨幅计数器跳到新年均价；趋势线生长一格；事件年触发旗标 + 闪光 + 抖动 + 音乐重音。
**事件卡点表**（画面动作 ↔ BGM 重音）：
1997 亚洲金融危机 · 1999 央行售金 20 年低点（暗红低音）· 2001 $255 大底 ·
2006 +36% 爆增（金闪）· 2008 破 $1,000→雷曼崩盘（红闪重击）· 2011 盘中 $1,921 冲顶（金闪最强之一）·
2013 黄金大劫案单日 -9%（红闪）· 2015 $1,046 六年大底（静场下潜）· 2019 降息周期启动 ·
2020 疫情 $2,075（重击）· 2022 俄乌 $2,070→加息回落 · 2024 +23% 央行狂买（riser 预警）·
**2025 +70% 史诗年（全曲最强重音，金光爆发）** · 2026 年内 $4,967 历史之最（收束重音）。
底部进度条按年份刻度推进；右下角常驻口径标注「LBMA 年均价 · 2026 为 YTD 估算」。

### 片尾（68–76s，bar33–36）
68s impact：前三名年份领奖台（2026 / 2025 / 2024）依次弹起 + 奖杯 + 金色纸屑雨；
70s 三枚统计卡弹入：累计 ≈11 倍（$388→$4,300+）· 最大年涨幅 2025 年末 +70% · 最大年跌幅 2013 -16%（年均口径）；
74–76s 金色光晕收束淡出 + 口径落款。

## 5. 时间轴与对齐规则

1. 帧网格：BPM=120 → 1 拍=15 帧、1 小节=60 帧；INTRO=180、RACE=31×60=1860、OUTRO=240，TOTAL=2280。
2. 年份 y（1996+i）占用竞速段帧 `180 + i*60` 起；其入场/重排/计数跳变必须发生在该帧 ±0。
3. 音乐 impact 已烘焙在 6.0/26/30/36/40/44/54/62/64/66/68/74.0s，画面事件吸附其上（±1 帧）。
4. 片尾 BGM 自然收束，不做硬淡出；SFX 只做点缀。

## 6. 验收标准

- [ ] 全片 1920×1080@30，总长 76s±0.5s
- [ ] 所有年份切换/榜单重排落在 2s 小节线上；事件闪光与 BGM 重音逐点对应
- [ ] 巨幅价格计数器逐位滚动、年切换有 spring 弹跳与红绿同比闪烁
- [ ] 2025 段为全片最强卡点（音乐最强重音 + 金光爆发）
- [ ] 无行星/太阳系/星空元素；金色尘埃与终端风格为本片原创
- [ ] 画面常驻数据口径标注；2026 明确标示 YTD 估算
- [ ] BGM 为程序化无版权生成，响度不削波、不盖音效
