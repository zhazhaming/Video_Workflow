# 每日一家公司 · 系列方案与首期初稿

> 目标：把「介绍一家公司」做成可持续的日更栏目，而不是一期一个百科朗读。
> 这份文档是选题、初稿模板和制作约束的说明；产品里的档期板在
> **视频流水线 → 🏢 每日公司**（深链 `/?tab=pipeline&track=company`）。

## 一、栏目定位

- **一句话**：每天拆一家公司，讲清它「靠什么起家、在哪一步翻身、到底靠什么赚钱」。
- **差异点**：不念成立年份和财报，先给一个反常识钩子，再用一个具体细节收尾。
- **时长**：45~60 秒（默认 50 秒）；竖屏 1080×1920，抖音安全画幅 `safeScale=0.8`。
- **固定结构**：开场（数字→反差→代价）+ 3 台阶（起家 / 转折 / 靠什么赚钱）+ 结尾互动；栏目标识「每日一家公司」放画面字幕，不占口播开场。
- **开场硬规则（每一期都必须遵守）**：0–5 秒 = 数字 → 反差 → 代价；前 5 秒禁止自我介绍、「本期/今天」、栏目名。
- **结构硬规则**：3 台阶 × 15 秒，每台阶结论先行；第 10 秒前必须交付第一个完整价值；全片不写固定开场白/结束语，不出现「我是阿扎」。
- **更新节奏**：一天一期；国内外交替、赛道分散，同一赛道 7 天内不重复。

## 二、三段台阶模板（可直接套）

| 段落 | 时间 | 要回答的问题 | 写作要求 |
|---|---|---|---|
| 开场 | 0-5s | 哪个数字最反常识？ | 第 1 句数字，第 2 句反差，第 3 句代价；每句 ≤20 字，禁止自我介绍 |
| 台阶 1 起家 | 5-20s | 谁、哪年、在哪、靠什么起家？ | 只留 1 个年份 + 1 个地点 + 1 个起点动作 |
| 台阶 2 转折 | 20-35s | 哪一步让它活下来/翻身？ | 讲一个决策，不要罗列发展史 |
| 台阶 3 赚钱 | 35-50s | 它到底靠什么赚钱？ | 一句话商业模式 + 一个记忆点（产品/梗/制度） |
| 结尾互动 | 50-60s | 让观众说句话 | 提问或点名下一期，不喊口号，不写固定结束语 |

写初稿时的三条硬规矩：

1. **每句 ≤20 字**，一句一个信息点，方便 TTS 和字幕。
2. **数字必须能溯源**；查不到出处的数字，改成定性表述（"门店数全球第一"要注明统计口径和时间）。
3. **不写"伟大""传奇""颠覆"** 这类形容词，用事实和细节代替。

## 三、首期初稿：蜜雪冰城

**备选标题**

- 4 块钱的柠檬水，怎么开出全球最多的茶饮店？
- 蜜雪冰城不赚你的钱，那它赚谁的钱？
- 一家河南小公司，把茶饮店开到了全球第一

**口播稿（约 70 秒，每句 ≤20 字）**

1. 4 块钱一杯柠檬水，它能赚什么？
2. 这家公司叫蜜雪冰城。
3. 1997 年，张红超在郑州摆摊卖刨冰。
4. 第一家店，只有几平米。
5. 别人涨价，它死磕低价。
6. 2 元冰淇淋，4 元柠檬水。
7. 便宜到让人怀疑：这能赚钱吗？
8. 能。但它赚的不是你的钱。
9. 它向加盟商卖糖浆、果酱和设备。
10. 门店越多，原料卖得越多。
11. 它自己建工厂、建冷链。
12. 把成本压到别人抄不动。
13. 2018 年，雪王诞生。
14. 一首主题曲，唱遍全国门店。
15. 你记不住财报，但记得住雪王。
16. 现在，它的门店数全球第一。
17. 便宜不是策略，是它的护城河。
18. 下一期想看哪家公司？
19. 评论区点名，我来拆。

**分镜建议（5 镜，浅色纸感）**

| 镜 | 对应台词 | 画面 |
|---|---|---|
| 1 | 1-4 | 米白纸面上一张 4 元小票特写，推近到「蜜雪冰城」字样 |
| 2 | 5-8 | 左右对比：涨价标签 vs 4 元价签；中间弹出「它赚谁的钱？」 |
| 3 | 9-12 | 供应链示意：工厂 → 仓库 → 门店，箭头逐个亮起 |
| 4 | 13-15 | 雪王剪影 + 音符/声波元素，节奏卡点 |
| 5 | 16-19 | 门店密度点阵铺满画面，收束到栏目 CTA |

**事实核验清单（制作期逐条查源，写入 research.json）**

- 1997 年、张红超、郑州、刨冰摊起家
- 2 元冰淇淋 / 4 元柠檬水的当前定价（不同城市可能不同，写「常见定价」）
- 收入主要来自向加盟商销售商品与设备，而非加盟费
- 自建工厂与冷链的说法
- 2018 年雪王 IP 上线
- 「全球门店数第一」的统计口径、时间与来源（茶饮连锁 vs 餐饮连锁要区分）

> 以上任何一条查不到权威来源，就在成片里删掉或改成定性表述，不要保留"大概对"的数字。

## 四、通用初稿骨架（换公司时只替换方括号）

```text
[开场：一个具体数字 + 一句反差，≤20 字/句]
[年份]，[创始人] 在 [地点] [起家动作]。
[转折：一个关键决策 / 一次濒死 / 一次押注]
[一句话商业模式：它到底靠什么赚钱]
[一个记忆点：产品 / 梗 / 制度 / 名场面]
[结尾一句话互动提问]
```

## 五、生产流水（已接进现有前端）

1. 打开 **视频流水线 → 🏢 每日公司**，在 7 天档期里选一天。
2. 从 35 家候选里选一家（可按国内/海外、赛道、关键词筛），系统生成三段台阶初稿。
3. 改标题、段落、CTA，点「保存初稿」。
4. 点「排产到下一档」→ 生成一个 `kind=company` 的流水线批次，到凌晨制作时间自动执行；
   也可「立即制作」马上跑。
5. 制作由现有 dsh agent 会话完成：选题细化 → 文案 → BGM → 配音 → 风格 → 渲染 → 事实审计 → 视觉验收。
6. 成片、日志、项目详情都在「🔥 热点流水线」的历史批次里查看。

**接口**（后端 `backend/app/routers/company.py`）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/company/pool` | 候选公司库 + 赛道/国家筛选项 |
| GET | `/api/company/plan?days=7` | 未来 N 天档期（空档带推荐公司） |
| POST | `/api/company/plan` | 为某天选公司（生成初稿） |
| PUT | `/api/company/plan/{date}` | 保存初稿 |
| POST | `/api/company/plan/{date}/draft` | 按候选库重新生成初稿 |
| DELETE | `/api/company/plan/{date}` | 撤下未排产的计划 |
| POST | `/api/company/plan/{date}/schedule` | 排产（`{"now": true}` 立即制作） |

## 六、制作约束（沿用工作区规则）

- **模板相关性**：公司介绍与渲染引擎内置领域模板无关，`plan.json` 的 `template` 必须是
  `from_scratch`；禁止行星/宇宙等无关动效，画面靠 prompt + 现场 gen 场景或中性排版。
- **事实闸门**：`script.json` + `research.json` 必须过 `backend/tools/facts_audit.py --strict`；
  流水线会按最终产物复核，不通过自动返修。
- **抖音安全画幅**：`safeScale=0.8`，内容安全区 x 185~895 / y 300~1460；
  字幕、数字、印章不要贴边。
- **浅色明亮**：米白/浅纸纹/明亮品牌色，禁止深色 AI 味背景。
- **动效**：每镜入场→展开→收束，关键数字有强调，切镜卡 BGM 拍点。
