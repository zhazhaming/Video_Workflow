# 写稿硬规则

> 来源：`llm.py` SYSTEM_PROMPT / FLOW_COPY_SYSTEM 与 `flow.py` 落盘校验层（`_split_line`/`_copy_to_script`）。
> 这些规则由后端校验强制过（20 字硬切、6 句上限、24 幕上限、hex 校验），skill 流程靠你自检遵守。

## 句子级（渲染窗口决定，违反会出框或换行难看）

1. **每句 ≤20 字**（终极上限 28 字，目标 20）：一句一个画面，长句在标点处拆开。
2. 短句、口语、有画面感，适合逐句 TTS；**避免**书面语、成语堆砌、emoji、括号说明。
3. 台词里**不出现引号、书名号**（强调词用 emphasis 机制表达，不用标点）。
4. 数字、年份、人名尽量写成阿拉伯数字（TTS 读法更稳，也是 emphasis 自动提取的目标）。

## 幕级

- 每幕 1~3 句（后端上限 8 句，别碰）。
- `label`：4~12 字小标题，概括本幕画面或情绪（占位画面/找图都靠它）。
- `year`：年代/阶段标签 ≤16 字，非年代故事留空字符串。
- `colors`：两个协调 hex `#RRGGBB`。默认**浅色纸感**（浅底 + 深墨字 + 一个低饱和强调色），不要默认深色底 + 霓虹色；情绪转折时用色彩变化配合（低谷冷暗、高潮亮燃）。

## 全片级

- 幕数：`clamp(round(target_seconds / 9), 8, 22)`（后端上限 24 幕）。60 秒 ≈ 7~9 幕 ≈ 16~22 句 ≈ 270 字。
- 总字数 ≈ `target_seconds × 4.5` 字；healing 等慢语气按 3.6~4 字/秒估。
- 结构四要素（FLOW_COPY_SYSTEM 硬要求）：
  1. **开头抛一个问题**让观众猜（或 2 句内抛出钩子：悬念/反差/痛点）；
  2. 中间当故事讲，**至少一个生活里的比方**；
  3. 安排**一次反转**（或高潮）；
  4. 结尾**落到普通人身上** + 互动引导（"评论区"类 CTA 最多一句）。
- 无解释就使用的专业术语，一律换大白话或当场用一句话讲清。

## 事实纪律（有 research.json / 调研资料时）

- 只允许使用资料里出现的事实；资料没有的不要编。
- 数字、年份、人名必须与资料一致；资料矛盾以更权威来源为准。
- 未证实信息一律"网传/据说"表述。
- 找不到可靠出处的知识点直接弃用，宁缺毋滥。

## 标点与后续停顿的关系（写稿时就考虑）

每句句尾标点决定渲染停顿（另加固定 0.45s 缓冲）：
`？!` → 0.6s ｜ `…` → 0.65s ｜ `。` → 0.5s ｜ `，、；` → 0.25s ｜ 其他 → 0.4s

- 钩子句用 `？`（停顿长，留思考时间）；递进句别用逗号收尾（听起来没说完）；幕末句用 `。` 或 `！`。
- 台词是给 TTS 读的：不要写"（停顿）"之类舞台指示，停顿交给标点。
