# video-script：视频文案

把一个选题写成**逐句可配音、逐句可上屏**的竖屏短视频脚本。你负责创作；硬规则与产物契约照本文执行。

## 输入

| 项 | 说明 | 缺省 |
|---|---|---|
| topic | 选题（一句话，含角度/钩子更佳） | 必须有 |
| target_seconds | 目标时长 15~240 秒 | 60 |
| tone | 语气配方 id（见 references/tone-recipes.md）或自定义要求 | 按题材自选 |
| research.json | 可选；有调研资料时**只允许使用资料里出现的事实** | — |

## 流程

1. **读规则**：`references/script-rules.md`（句长/幕数/结构/禁则）——写稿前必读。
2. **选语气**：按题材气质从 `references/tone-recipes.md` 五种配方里选一种（story/suspense/knowledge/healing/roast），或采用用户自定义要求（优先级最高）。
3. **定幕数**：`clamp(round(target_seconds / 9), 8, 22)`；总字数 ≈ `target_seconds × 4.5` 字（中文口播语速）。短创作视频（<8 幕）可灵活，但结构四要素不能缺。
4. **写稿**：先列情绪曲线（低谷→积蓄→爆发→收尾），再逐幕落台词。台词面向"观众只看画面上的字"来写——短、口语、有画面感。
5. **自检**：对照下面清单逐条过，不过就改稿。
6. **落盘**：按 `references/script-schema.md` 写 `backend/storage/projects/<pid>/script.json`，并向用户简报（标题、幕数、预估时长、结构亮点）。语气拿不准时先给 2 个方向让用户挑。

## 自检清单（全过才交付）

- [ ] 每句 ≤20 字（硬规则，超了拆句）；每幕 1~3 句
- [ ] 结构四要素：开头问题钩子 → 中段至少一个生活化比方 → 一次反转/高潮 → 结尾落到普通人 + 互动引导（CTA 最多一句）
- [ ] 无书面语、无成语堆砌、无 emoji、无括号说明、台词里无引号/书名号
- [ ] 专业术语要么换大白话要么当场一句话讲清
- [ ] 有 research.json 时：全部事实来自资料，数字/年份/人名与资料一致，没有编造
- [ ] colors：每幕两个协调 hex，默认浅色纸感底 + 低饱和强调色，贴合该幕情绪（暖=亮/燃，冷=暗/沉）
- [ ] 总字数与 target_seconds 匹配（±20%）

## 与其他阶段的关系

- 本 skill 只产出 script.json；配音（tts_gen）、BGM、风格分镜（plan.json）、渲染由后续阶段做。
- 用户对稿子提修改意见 → 直接改 script.json 重落盘，不必重跑其他阶段。
- 台词的标点会影响后续停顿（？!→0.6s，。→0.5s，，→0.25s），该断句断句、该收尾收尾，别一逗到底。
