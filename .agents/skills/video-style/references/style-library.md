# 画风风格库（29 种动效画风提示词包）

> 来源：2026-11 从视频《动效大片 · 29 种风格盘点（带提示词）》逐帧转录，并与上游开源项目
> [LearnPrompt/carl-motion](https://github.com/LearnPrompt/carl-motion)（提示词部分 MIT 许可，演示视频 CC BY 4.0/link-only）交叉校验。
> 用途：video-style 流程的**扩展画风候选池**。用户点名某种画风、或按题材气质选画风时，从本库取卡。
> 视觉速查：`style-library-sheet.jpg`（3×10 格，行序=①→㉘ 风格卡顺序，每格顶部是源视频的段号计数，写 gen 场景前先看一眼目标格找手感）。
> 本库是"通用画风"提示词包，**不属于领域模板**：任何选题按总入口 ★规则判定仍走 `from_scratch`，
> 画面用 gen 场景（`remotion-engine/src/gen/<pid>/SceneNN.tsx`）现场实现；结论照常落 `plan.json` 的 `template` 字段。

## 怎么用

1. **选风格**：先按题材气质查 §选择决策表；用户已指定画风就直接取卡。
2. **写 look**：风格卡给了 `mode` 与色板方向，映射进 plan.json 的 `look`（preset 就近取
   paper/editorial/cinema/graphic/dark，palette 用风格卡色板，字体按 style-rules.md 硬约束）。
   风格卡的色板即画面主色，**优先级高于默认 accent 建议**。
3. **写场景**：把"你的主题"替换成本期选题主体，按卡的「画面要点 + 失败点 + 落地要点」写 gen 场景。
   原提示词面向一次性代码生成（HTML/Canvas/Three.js/Blender 出 MP4），在本工作区统一落地为
   Remotion gen 场景；「落地要点」标注了 ✅直接可做 / 🔶变通近似 / ⛔不建议 三档。
4. **硬约束仍然生效**：字幕 ink 对背景对比度 ≥4.5:1、safeScale 0.8 内容安全区、运镜 ≤1.1。
   深底风格（③⑧⑬㉑㉒㉙ 等）只有当**整片就是这种风格**时才选（这是风格决策，不是 AI 味）；
   默认提案仍按 style-rules.md 至少两个浅色方案。
5. **确定性**：所有随机（网点、笔触、抖动、粒子）用 `src/dv/atmosphere.ts` 的 `rand`，保证可复现。

## A · 手作纸面系（浅色，默认提案优先从这里出）

### ① 复古纸张拼贴 · retro-paper-collage（原栈 HTML，原难度 1）✅
- 画像：旧报纸+牛皮纸底上贴抠图素材，剪刀白边、半调网点、卡顿手抖，勒索信拼字感。
- 提示语模板：用 HTML 做你的主题的复古纸张拼贴，素材抠图加白色剪刀边和半调网点，运动降到 12 帧，加轻微手抖。画面要点：报纸牛皮纸底、抠图加 2~4px 白剪刀边、halftone 网点、12fps 乃至 6fps、正负 2px 手摆抖动、拍上来与翻页转场、红黑构成主义字、勒索信拼字。
- 失败点：满帧顺滑就像 PPT 动画（要降帧+每拍轻抖）；缺撕边和投影会退化成扁平拼贴；字体只用一种就没有拼贴味。
- 落地要点：纸纹用噪点渐变，白剪刀边=白色描边+不规则 clip-path，halftone 用径向渐变点阵；12fps=按 `Math.floor(frame/2.5)` 分步，抖动用 `rand` 限幅 ±2px；红黑双色即 look（mode:light, accent 朱红）。

### ④ 纸面手绘笔记 · hand-drawn-notes（原栈 HTML，原难度 2）✅
- 画像：米白纸上的步骤教程动画，细线手绘器物，每加一样东西同步跳出名称和用量。
- 提示语模板：用 HTML 在米白纸面上做你的主题的步骤动画，手绘细线画器物，每加一样东西就同步跳出名称和用量。画面要点：米白纸面、手绘细线器物、手写体标题与用量、步骤编号卡、从空到成品、刻度线、讲解节奏。
- 失败点：字和动作不同步就没有讲解感（每一步同一拍出现）；线条太规整像图标库；颜色一多压住手绘感。
- 落地要点：SVG path + strokeDashoffset 逐段绘制，线条加微抖动（两三版 path 交替）模拟手绘；步骤卡与绘制用同一时间轴拍点；配 NotoSerifSC 手写感标题。适合教程/食谱/流程类。

### ⑤ 水彩手绘 · watercolor（原栈 Canvas，原难度 2）✅
- 画像：会自己上色的水彩手账，透明笔触层层叠、干笔飞白、纸白当高光，逐笔上色。
- 提示语模板：用 Canvas 画一页会自己上色的水彩手账，主题是你的主题，透明笔触一层层叠，干笔飞白，纸白留作高光。画面要点：暖色棉纸纤维、透明 wash 越叠越深、dry-brush 飞白、纸白当高光、手写批注加引线、逐笔上色、薄雾擦除转场、赭石灰蓝低饱和。
- 失败点：矢量形状贴水彩纹理一眼就假（要用变宽笔触和毛刷边）；亮部要留纸白；颜色别填满整块。
- 落地要点：预生成笔触路径列表（变宽多边形 + 边缘毛刺），按 alpha 0.08~0.15 多层叠加；逐笔 reveal 用时间轴切片；转场用低透明白色薄雾擦除。色板：纸白 #F5F0E6 / 赭石 / 灰蓝。

### ⑥ 黑白木刻版画 · woodcut（原栈 Canvas，原难度 2）✅
- 画像：整块黑版，亮部是刀刻出的白线，一刀一刀刻出来，最多留一种红。
- 提示语模板：把你的主题做成黑白木刻版画，整块黑版，亮部是刀刻掉的白线，画面一刀一刀刻出来，最多留一种红。画面要点：黑底白刻、光是刻出来的、逐刀刻出不深入、粗刀在前细线在后、刀线随形体走、最多一种颜色、纸边留白、反字印出转场。
- 失败点：每个面都排线会像毛和雨（只在受光边刻三到六刀）；画面用淡入出现就不像刻的；颜色都留一种。
- 落地要点：黑色底版 + 白色刀线（宽窄两种）沿形体方向排布，受光面 3~6 刀；出现方式=刀路逐段刻出（dashoffset），不用淡入；红色只给一枚印章或一点强调。mode 可 light(纸白版) 或 dark(黑版)，字幕对比度按所选底算。

### ⑨ 蓝图工程制图 · blueprint（原栈 Canvas，原难度 2）✅ 强推科普
- 画像：普鲁士蓝晒图纸上白细线按绘图顺序画主题，配尺寸线、编号气泡、title block。
- 提示语模板：用 Canvas 在普鲁士蓝晒图纸上，用白色细线按绘图顺序画出你的主题，配尺寸线、编号气泡和图框。画面要点：cyanotype 蓝晒纸、白色工程细线、逐层绘制顺序、尺寸线与引线、编号气泡、title block 图框、剖面线、整张图纸平移缩放。
- 失败点：做成 3D 或发光线框就不像了（只用蓝白两色 2D 线稿）；线条一次全出现会丢掉绘制感。
- 落地要点：底 #16305e 系蓝晒色，线全部 #E8EEF5；strokeDashoffset 逐层绘线（先主轮廓后细节后标注），标注气泡最后弹出；整图 slow zoom/p pan ≤0.6。subtitleStyle 用 bold 白字。

### ⑫ 中国水墨 · chinese-ink-wash（原栈 代码，原难度 1）✅
- 画像：宣纸水墨动画，五档墨色、留白过半、一笔一笔画出来、一枚朱红印章。
- 提示语模板：用代码在宣纸上画你的主题的水墨动画，只用五档墨色，留白过半，笔触一笔一笔画出来，只盖一枚朱红印章。画面要点：写意、程序宣纸纹理、墨分五色、没骨带墨量笔触、飞白干笔、留白六到八成、墨晕转场、一枚朱红印章。
- 失败点：矢量描边加笔刷贴图很假（要带墨量的枯毛笔笔触）；不画闭合轮廓；留白一少就成了彩色画。
- 落地要点：笔触=多段锥形宽度的填充形（起笔重收笔飞白分叉），灰阶五档 #1a1a1a~#c9c4b8；宣纸底 #EFE8D8+纤维噪点；墨晕转场=大半径低透明度墨团扩散；印章一枚 #C8452D。强烈适合财经/文化/叙事。

### ㉓ 古埃及壁画 · egyptian-mural（原栈 Canvas 2D，原难度 2）✅
- 画像：墓室壁画程式：正身侧脸、分栏横带、象形文字栏、赭石青金平涂黑描边、石墙质感。
- 提示语模板：用 Canvas 2D 把你的主题画成古埃及墓室壁画，人物侧脸正眼，分栏横带构图配象形文字栏，赭石青金平涂加黑描边。画面要点：侧脸正眼程式、分栏横带 register、象形文字栏、赭石青金孔雀绿土黄平涂、黑色描边、太阳光线末端小手、墙面石材质感。
- 失败点：加透视和阴影就不像壁画（整画是平的）；人物要正身侧脸规范姿势；颜色只用赭红、土黄、青绿这类矿物色。
- 落地要点：横带分 3~4 层 register，人物用简化正侧身图形库（头侧眼正肩正腿侧），文字栏用竖排假象形符号条；平涂+3px 黑描边；动态只给河水波纹/光线摆动等局部。历史文化题材独一档。

### ㉕ 纸面编辑式数据叙事 · editorial-dataviz（原栈 Canvas，原难度 1）✅ 强推数据
- 画像：米色点阵纸上红蓝铅笔逐点画真实数据，手写批注钉在数据点旁，图表本身当镜头。
- 提示语模板：用 Canvas 在米色点阵纸上画你的主题的真实数据，红蓝铅笔逐点画出，手写批注钉在数据点旁，图表本身当镜头。画面要点：米色点阵纸、真实数据逐点绘制、红蓝铅笔笔触、手写批注钉在数据点、RdBu 发散色阶、图表即镜头、按数据选图型。
- 失败点：别做成仪表盘或幻灯片；一次只讲一个观点；转场只用图表本身的变化。
- 落地要点：数据必须真实（硬闸门），逐点/逐柱生长动画，批注用手写体+NotoSerifSC；"图表即镜头"=对当前数据区域做 push/pan（≤1.1）；涨跌配色可接 A股 红涨绿跌规则。本工作区数据题材首选之一。

### ㉘ Risograph 孔版套印 · risograph（原栈 代码，原难度 2）✅
- 画像：孔版印刷：两三种专色正片叠底、半调网点、轻微套印错位、色块不描边。
- 提示语模板：用代码模拟孔版印刷做你的主题，两三种专色正片叠底，带半调网点和轻微套印错位，色块不描边。画面要点：专色分版叠印产生第三色、半调网点、grain 与针孔、暖白纸、12fps 角色帧配 24fps 镜头帧。
- 失败点：矢量图加噪点不算（每块颜色都得来自分版叠印）；没有套印错位就不像；三块版的网屏角度要互相错开。
- 落地要点：每色独立图层（globalCompositeOperation:'multiply'），各带 1~2px 错位与不同角度网点纹理（叠加 multiply 网点 pattern）；纸底暖白 #F6F1E7；抽帧节奏。复古海报感强，适合盘点/榜单。

## B · 数字讲解系（多为浅色图形感，讲解/产品强）

### ② 产品界面 2.5D 运镜 · product-ui-2-5d（原栈 Remotion，原难度 2）✅ 完美契合
- 画像：真实产品页面截图 3D 倾斜做 2.5D 运镜，关键信息停留一秒以上，卡点数字滚动。
- 提示语模板：用 Remotion 把你的产品真实页面截图做成宣传片，截图 3D 倾斜做 2.5D 运镜，关键信息停留一秒以上。画面要点：真实页面截图、2.5D 页面相机、页面倾斜后分层、卡点剪辑、数字滚动、闪帧、关键信息停留一秒。
- 失败点：节奏太快、整屏一拍一抖会廉价（放慢一档）；界面字要真实可读（糊成灰条就像占位图）；视角来回变会晕。
- 落地要点：**本引擎就是 Remotion，天然主场**：截图 img + perspective/rotateY/translateZ 分层，运镜用 interpolate 缓动一次到位，数字滚动 spring；截图放 `public/pic/projects/<pid>/`；与 BGM 卡点对齐 timeline。
- look 映射：mode light、bg 米白/浅灰，subtitleStyle bold。

### ⑩ 贴纸科普 · sticker-explainer（原栈 HTML，原难度 2）✅ 强推科普
- 画像：超大画布上白边贴纸照片+扁平图标+精确图表，蓝灰米白底两三色，镜头缓慢平移缩放。
- 提示语模板：用 HTML 大画布做你的主题的科普动画，照片抠图加 10px 白边做成贴纸，蓝灰底只用两三种颜色，镜头在画布上平移缩放。画面要点：照片抠图白描边贴纸、蓝灰米白底、两三色加一个强调色、扁平图标配精确图表、超大画布、长缓慢平移缩放、柱状生长与数字滚动。
- 失败点：配色超过三种就散；柱高和数字比例要准（否则没有科普的严肃感）；贴纸缺白边和投影就只是普通抠图。
- 落地要点：贴纸=img + 10px 白边（border/滤镜）+ drop-shadow；画布做成 2~3 屏宽，用 pan 逐区带过；柱状生长 spring、数字 counter；图表数据真实。与 A股/科普题材契合度最高。

### ⑭ 等轴 2.5D 世界 · isometric-world（原栈 Canvas/Three.js 正交，原难度 2）✅
- 画像：等轴测微缩世界，每面三色调平涂，小图标引线标数据，建筑生长、剖开 cutaway。
- 提示语模板：用 Canvas 或 Three.js 正交相机把你的主题做成等轴测微缩世界，每个面三色调平涂，用小图标和引线标数据。画面要点：true isometric 30 度、每面三色调平涂、悬浮底座带剖面、isotype 图标计数、标签引线、剖开 cutaway、建筑生长带过冲、沿路线带镜头。
- 失败点：夹带透视就变成低多边形 3D（固定 30 度等轴）；不描边；镜头乱转会破坏等轴感。
- 落地要点：Canvas 2D 等轴投影（x'=(x-y)·cos30, y'=(x+y)·sin30·0.5），三色=每面顶/左/右明度阶梯；建筑生长用 scaleY+overshoot；镜头只沿轴平移或整图缩放，禁止旋转。城市/产业链/系统架构题材首选。

### ⑱ 像素游戏 · pixel-game（原栈 Canvas，原难度 2）✅
- 画像：320×180 内部分辨率、最近邻放大、16~32 色有限色板、精灵阶梯帧动、背景视差。
- 提示语模板：用 Canvas 320×180 内部分辨率画你的主题，最近邻放大 6 倍，限定 16 到 32 色，精灵按阶梯帧帧动，背景分层视差。画面要点：低分辨率大像素、16~32 色有限色板、nearest-neighbour 整数放大、8~12fps 精灵帧、视差卷轴、steps() 阶梯时序、dithering、游戏 HUD 字。
- 失败点：平滑缩放或平滑移动会把像素糊成马赛克（坐标和位移全取整数）；调色板限 16~32 色。
- 落地要点：gen 场景内建 offscreen 小画布，输出层 imageRendering:'pixelated'；所有坐标 `Math.round`，动画帧 `Math.floor(frame/3)`；HUD 用 JetBrainsMono。游戏/怀旧/科技史题材。

### ⑬ ASCII 字符视觉 · ascii-crt（原栈 代码，原难度 2）✅
- 画像：等宽字符网格拼出主题，琥珀色单色 CRT 荧光屏，扫描线辉光，推拉靠改字号。
- 提示语模板：用等宽字符网格拼出你的主题，琥珀色单色 CRT 荧光屏，加扫描线和辉光，推拉镜头靠改字号来做。画面要点：monospace 字符网格、琥珀或绿色荧光单色、CRT 扫描线与桶形畸变、bloom 辉光、字符密度梯度、光标闪烁、改字号推拉、打字机字幕。
- 失败点：整张图套 ASCII 滤镜一看就是滤镜（每一处亮点都得是网格里的真字符）；字符集太少画面糊。

## 与 look / plan 的对接速查

- **浅色卡**（①④⑤⑥⑨⑩⑫⑭⑱⑲㉓㉕㉖㉘ 等）：look.mode=light，palette 直接用卡内色板，texture.paper/grain 按风格开。
- **深色卡**（③⑧⑬㉑㉒㉙）：只有整片定成该风格才选；look.preset=dark，字幕/标注用米白 #F2EDE4 系保证 ≥4.5:1；提案模式里最多一个深色方案。
- **提示语复用**：写 gen 场景的 design prompt 时，可把卡内「提示语模板 + 画面要点」原文粘进场景说明（替换"你的主题"），「失败点」作为场景自检清单。
- **音效**：手作系配纸张/笔刷 sfx（public/sfx），3D 系配低频 thump；sfxMoment 全片 ≤3 次。
