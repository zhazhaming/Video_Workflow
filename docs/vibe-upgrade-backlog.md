# 对标「Vibe 知识大赏」改造清单（暂缓执行）

> 来源：2026-11-04 对标测评。参考片①：Iwanau《偶然之书·运气的形状》
> （61.6万赞/13.3万收藏，2:10，1080p 横屏，用户下载件实测）。
> 状态：**已评审、暂不实施**；按优先级排序，动手前先读 `AGENTS.md` 模板相关性规则
> 与 `.agents/skills/video-producer` 契约。

## P1 · BGM 母带与低频升级（`backend/tools/gen_event_bgm.py`）

实测依据：参考片整体 RMS 0.459（≈-6.8dBFS）vs 我们 0.321（≈-9.9dBFS），
**响度差 3dB**；sub<80Hz 占比 69.5% vs 我们 48%（808 类厚低频是"激起感"来源）；
他们的能量弧片尾仍保持 0.46，我们末段塌到 0.10（收尾泄气）。

- [ ] 母带目标 RMS ≥0.42（总线 tanh 后归一系数 0.88 → 提高 + 压缩更狠）
- [ ] 新增圆润 808/sub 持续低频层（现只有 kick 点状冲击）
- [ ] BPM 档位默认 108~112（groove 律动档；128 偏赶，实测参考片 112.3）
- [ ] outro 不塌：能量保持到最后一拍，尾部淡出 ≤0.8s（现 1.6s 渐弱+能量早衰）
- [ ] 人声不闪避、音乐满铺（他们全程 0 静音，音乐当地毯非垫子）

## P2 · 编年体「章节语法」组件（remotion-engine 排版层）

实测依据：参考片 130s 约 20 章，固定语法 =
`左上年代戳（大年份+城市·人名）+ 右上书名引用（拉丁文斜体+红色小书标）
+ 居中专属图 + 底部一句字幕`，每章 5-8s。

- [ ] 新增 `EraStamp` 排版组件：大年份衬线数字（金）+ 城市·人名小字
- [ ] 新增 `CiteCard` 引用卡：右上书名（原文斜体+中文译名+小红书标）
- [ ] 新增片尾 `References` 卷轴（5s，12+ 条出处滚动/静止展示）
- [ ] look 新增 `cinema+gold` 预设（暗底 + 金/象牙 accent，非霓虹，过 AI 味禁令）

## P3 · 多形态信息图库（gen 场景层，一屏一图一物）

实测依据：参考片 130s 内 14+ 种完全不同的定制可视化
（骰子/幸运骨/对局进度条/组合方阵/对比卡/地图连线/概率树/羊皮纸/粒子云/
陶罐抽球/收敛折线/钟形曲线/布丰投针/钉板/公理卡），我们全片 1 套图表语法。

- [ ] 对局/对比卡组件（双列进度条 + 百分比 + 胜负标）
- [ ] 地图连线组件（两点+虚线航线）
- [ ] 粒子云 / 收敛折线 / 钟形曲线生长（部分可复用 atmosphere rand）
- [ ] 实物锚：CSS 3D 骰子、硬币、羊皮纸卡（transform 可做伪 3D，不必上 three.js）
- [ ] 留白章：几乎全黑只留年代戳与一句字幕（呼吸拍）

## P4 · 文案编年体配方（video-script tone-recipes）

实测依据：叙事 = 一个问题跨四百年接力（1485 帕乔利 → 1654 帕斯卡-费马 →
1873 高尔顿 → 1933 柯尔莫哥洛夫 → 2026 此刻·你），开场物件冷开场 +
首尾呼应（同一颗骰子），结尾"落到此刻的你"。

- [ ] tone-recipes 新增 `chronicle` 配方：每幕 = 年代 + 人物 + 冲突，一屏一事
- [ ] 开场冷开场（物件 + 格言式一句），首尾呼应物件在 plan 里登记复用
- [ ] 片内互动点：像第 4 集那样设计"暂停，换成你怎么选"（评论区站队引擎）
- [ ] 时长档：知识区中片 100-150s（幕数 10-16）或长片 5-10min（另议）

## P5 · 双画幅输出

实测依据：参考片 1920×1080 横屏电影感（B站/西瓜双投），我们竖屏抖音原生。

- [ ] remotion-engine 增加 Root comparison 1080p 横屏 comp（`CinemaVideo`）
- [ ] render_video.py 支持 `--orientation landscape`（1080×1920 ↔ 1920×1080）
- [ ] 决策规则：抖音信息流主发竖屏；横屏作为"知识大赏风格"选项

## 追加：参考片② 实测（9:44 物理长片《电场》，1080p 横屏，490kbps）

三条产品线证据（同口径实测）：

| 维度 | 片①音乐叙事型 2:10 | 片②课程长片型 9:44 | 我们 61s |
|---|---|---|---|
| RMS | 0.459（响度战争） | **0.182（全程平直，无能量弧）** | 0.321 |
| 频段主体 | sub 69.5%（音乐主导） | **mid 40.7%（人声主导）** | sub 48% |
| BPM | 112 groove | 110（薄垫乐） | 129 |
| 结构 | 20 章编年体 | **3 章+终章，右上进度点 ●●●○○** | 7 幕 |
| 留人机制 | 音乐+海报展览 | **一个比喻贯穿（电势=地形）+ 考点/口诀/陷阱卡 + 终章思维导图** | 卡点+事件特效 |

片②新增可抄项（并入上面 P2/P3/P4 执行时参考）：
- [ ] 右上**章节进度点**（●●●○○）——观众永远知道自己在哪（并入 P2 EraStamp 组件）
- [ ] **终章思维导图**：全片压缩成一棵树（"电场看坡度 电路看高度 实验看图像"），
      收藏引擎；我们可做"一图看懂这一年"复盘卡
- [ ] **考点/口诀/陷阱卡**：金色横幅口诀（"大内偏大·小外偏小"）、陷阱警示卡——
      实用价值锁收藏；我们对应"数据速查卡"（点位/涨跌幅/关键日期）
- [ ] **开场弹幕气泡**：把真实用户痛点做成聊天气泡开场（"你最怕哪一块?"）——
      我们可做"一打开账户就绿?"式共鸣开场
- [ ] 长片冷静响度哲学：课程内容 retention 不靠响度靠密度（与片①响度战争是
      两种路线，按内容类型选）
