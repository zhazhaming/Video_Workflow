## 这一版解决什么

| # | 改动 | 位置 | 结果 |
|---|---|---|---|
| 1 | **统一时间轴**：offset 吸附到拍（110 BPM → 2.182s），切点算法统一为「保底→吸附→低于保底取下一拍」 | `timeline.ts` / `voice.py` / `build_props.py` | props `sceneStarts` 与引擎逐帧一致；BGM 不再晚 0.7~1.4s |
| 2 | **BGM 事件绑定到台词**：`bgm_events` 增加 `line` 字段，事件落在念到该句的起点 | `build_props.py` / `build_config.json` | 3/23、5/13 等重音不再迟到 |
| 3 | **数据游标事件驻留**：gen 场景接收 `marks`（逐句时间窗），`YearChart` 用 `stops` 把 p 映射到交易日；念到事件时停在事件日 | `types.ts` / `DataVideo.tsx` / `chart.tsx` / `Scene01-07` | 字幕说 3599，右上就是 3599；不再出现 10/30 字幕配 9/30 读数 |
| 4 | **停顿去等距**：LEAD .9→.45、TAIL .6→.4、BONUS .45→.12；`pauseAfter` 按标点/数字自动给 | `timeline.ts` / `voice.py` / `build_props.py` | 有声占比 55.5%→**62.0%**；全片 61.6s→**56.3s**（剪掉约 10s 死等） |
| 5 | **片名平衡断行**：按标点/拉丁词边界断行，末行 ≥3 字，数字用 accent | `TitleCard.tsx` | 「一年，跌了 / 将近8%」，不再出现孤字「8%」「吗」 |
| 6 | **片尾复盘卡全屏化**：不透明底、内容区避开字幕带、标题改为「这一年，三个数字」 | `chrome.tsx` / `Scene07.tsx` | 不再压住全年图/坐标轴；截图可读 |
| 7 | **删互撞卡**：来源卡、速查卡、stat/counter 浮层、低点标签 | `Scene04/05` / `plan.json` / `chart.tsx` | 一屏最多一个主数字；图区/读数区不再互相盖 |
| 8 | **字幕逐 token 揭示**：每句按 2~4 字分段错 1~2 帧出现，强调词轻微过冲；`age` 修复了旧版只有每镜第一句会 pop 的 bug | `Subtitle.tsx` / `DataVideo.tsx` | 字幕有“被说出来”的节奏，不是整句硬切 |
| 9 | **逐句微节拍**：每句开头 8 帧 0.8% 推近缓出 | `DataVideo.tsx` | 8s 长镜里每 2~3s 有一次画面呼吸 |
| 10 | **转场去黑**：场景根节点不再铺不透明底色；实底放进 `TransitionIn` 内部；slide/zoom/whip 改为位移/缩放实底覆盖；旧镜延长到下一镜入场完成 | `DataVideo.tsx` / `motion.tsx` | 不再“先黑一下再亮”，也不出现双标题/双坐标轴重影 |
| 11 | **开场数据对齐**：Scene01 直接画全年到 11/2，游标停 3638/+1.08% | `Scene01.tsx` | 第一句「昨天大涨1.08%」与画面一致 |
| 12 | **QA 不再自证**：实际切点检测 + 落拍按 2 帧容差；旧常量同步更新 | `qa_report.py` | 旧版「props 绿、成片偏 1.4s」的假阳性会被抓出来 |
